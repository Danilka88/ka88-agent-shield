## Contributing Translations

To add a new language:

1. Copy `README.md` as template
2. Translate to your language
3. Name file: `README.<locale>.md`
4. Add entry to this table

Thank you for your contributions! 🌐

## Добавить перевод

Чтобы добавить новый язык:

1. Скопируй `README.md` как шаблон
2. Переведи на свой язык
3. Назови файл: `README.<локаль>.md`
4. Добавь запись в эту таблицу

Спасибо за вклад! 🌐
